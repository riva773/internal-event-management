# 社内イベント掲示板

## アプリURL
https://internal-event-management.bubbleapps.io/version-test/sign_up


## 概要

社内イベントや勉強会を登録・共有し、社員がイベント内容を確認して参加申し込みできるWebアプリケーションです。

利用者はイベントの一覧・詳細を確認し、開催前のイベントへ参加申し込みできます。主催者は自分が作成したイベントの参加者を確認し、イベントの編集・削除を行えます。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| ユーザー認証 | 新規登録、ログイン、ログアウト |
| イベント登録 | タイトル、開催日時、開催場所、定員、詳細を登録 |
| イベント一覧 | 登録済みイベントを一覧表示 |
| イベント検索 | タイトル・開催日を条件にイベントを検索 |
| イベント詳細 | タイトル、開催日時、開催場所、参加人数、主催者、詳細を表示 |
| 参加申し込み | ログインユーザーがイベントへ参加申し込み |
| 参加者確認 | 主催者が自分のイベントの参加者を確認 |
| 編集・削除 | イベント作成者のみ、自分のイベントを編集・削除 |

## 操作方法

1. 新規登録またはログインします。
2. イベント一覧から、開催予定のイベントを確認します。
3. タイトルまたは開催日を指定してイベントを検索できます。
4. 詳細ボタンからイベントの内容を確認します。
5. 条件を満たすイベントには参加申し込みできます。
6. 主催者は、自分が作成したイベントの参加者を確認できます。

## 工夫したところ
実際に使用することを意識して、フラッシュメッセージを表示するようにしました。

イベントの見つけやすさを重視して、一覧表示の際に開催日が新しい順に並ぶようにし、ページネーションをつけました。

一覧ページの開催済みのイベントにはグレー背景をつけて、開催前かどうかぱっと見で判断できるようにしました。

## 追加した機能と、その理由

追加した機能は、検索機能と自身が参加予約したイベントを表示した機能です。

検索機能については、イベントが多くなった時に参加したいイベントを見つけづらくなるという問題が発生するのではないかと考え、追加しました。

参加予定のイベントを表示した機能についても、実際に使う際に自身が参加するイベントを確認できた方が使い勝手がいいと考え、イベント一覧ページに参加予約済みの一覧を並べるようにしました。

## 難しかったところ

フラッシュメッセージを表示したページをリロードした場合に、リロード後はメッセージが表示されなくするという処理の実装に苦戦しました。

イベント参加予約後にイベント一覧に遷移し、フラッシュメッセージが表示されるのですが、開発中に一覧ページをリロードしたところ、もう一度メッセージが出てしまいました。

リロード後に表示されなくするためにページ読み込み時のワークフローで再度go to pageを組み込み、意図的にURLをリセットする処理を作ることで解決しました。

## 改善したいところ

レスポンシブ対応をすることでより使い勝手の良いサービスになると考えています。

また、開催後のイベントの様子(イベント時の画像など)を開催後に投稿し、それを参加していない人も閲覧できる機能を作ることで、
社内イベントの参加率向上につながるかもしれないと考えています。
